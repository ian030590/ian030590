## 我在做什麼

- **數位復能與視覺練習**：開發居家動作、視覺、認知與口腔練習工具，探索眼動追蹤設備與互動式活動的整合。
- **臨床與研究工作流**：把門診叫號追蹤、PubMed 文獻搜尋與 Zotero 論文整理等重複工作做成工具。
- **文件與日常自動化**：以 Python 處理 PDF 合併、分割、密碼移除，以及影像與 PDF 格式轉換。
