## 我在做什麼

- **數位復能與視覺練習**：開發居家動作、視覺、認知與口腔練習工具，串接眼動追蹤設備與互動式活動。
- **臨床科普寫作**：依指引與原始文獻整理中風復健、視覺復健、認知復健與 AI 應用，寫成讀者能理解的繁體中文文章。
- **臨床與研究工作流**：把門診叫號追蹤、病歷記錄、教具借用等重複工作做成工具。
- **文件與日常自動化**：以 Python 處理 PDF 與影像格式。
