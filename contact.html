常見諮詢與合作問題解答

在您正式聯繫前，這裡整理了臨床同仁與技術夥伴最常詢問的關鍵疑問。

01

是否提供臨床機構或治療所的客製化評估系統建置？

是的。可針對臨床科別（如神經復健、小兒發展、長照認知促進）進行專屬量測指標客製化，支援眼動刺激、手部精細動作追蹤與標準化反應時間測量，所有資料皆能匯出為符合研究規範的 CSV / JSON 格式。

verified支援本機離線與無資料外洩部署
02

居家訓練網 (trainerhub.cc) 的遊戲如何安全部署？

平台採 5 重多層防禦架構：包含獨立遊戲子網域、極致受限的 Iframe Sandbox、MessageChannel 專屬安全雙向管道，以及單一遊戲可轉化為獨立 PWA 安裝。臨床個案無須安裝可疑執行檔，隨開隨練。

shieldCSP 嚴格防護與沙盒隔離機制
03

辦公自動化工具（如 NTUHNotifier、文獻追蹤）是否有開放原始碼？

絕大多數工具均在 GitHub (ian030590) 完全開源。NTUHNotifier 門診通知擴充、PDF 萬用轉換解鎖工具與 ResearchAssistant n8n 檢索工作流皆附有詳細的原始碼與部署說明文件，歡迎自由 Fork 與修改。
